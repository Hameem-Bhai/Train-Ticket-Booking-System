## 🐛 Troubleshooting

### Email Not Working?
1. Go to Settings tab
2. Check if credentials are entered
3. Use App Password (not regular password!)
4. Click "Send Test Email" first

### Can't Book?
- Make sure API server is running (it started automatically)
- Check train ID exists (TR001, TR002, etc.)
- Verify date format: YYYY-MM-DD

### UI Looks Different?
- Maximize the window for best experience
- All tabs should be visible at top
- Dark theme with blue accents
