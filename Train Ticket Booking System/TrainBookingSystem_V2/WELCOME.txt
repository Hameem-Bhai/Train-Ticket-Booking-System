🚀 QUICK START:

   1. Double-click START_ULTIMATE.bat
   2. Wait for API to start (automatic)
   3. Modern GUI launches
   4. Click "Register Now" for first time
   5. Enter Gmail, get verification code
   6. Verify and start booking!

📧 EMAIL SETUP (For Ticket Delivery):

   1. Go to https://myaccount.google.com/security
   2. Enable 2-Step Verification
   3. Generate App Password (not regular password!)
   4. Open Settings tab in app
   5. Enter Gmail + App Password
   6. Save - You're done!
